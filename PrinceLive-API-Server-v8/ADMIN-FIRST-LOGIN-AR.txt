بيانات الدخول الأولية إلى لوحة إدارة PrinceLive v8.0.1
====================================================
اسم المستخدم: admin
كلمة المرور: admin123

افتح http://localhost/admin/ ثم أدخل البيانات أعلاه في شاشة الدخول داخل اللوحة.
كلمة المرور مخزّنة في config.json مشفّرة بـ scrypt مع salt داخل كائن admin، ولا توجد كلمة مرور بديلة.
لتغيير كلمة المرور: ولّد hash جديد بـ scrypt لنفس الـsalt أو salt جديد وحدّث `hash` في config.json.
غيّر كلمة المرور بعد أول دخول، ولا تشارك هذا الملف أو ترفع الحزمة علناً.
