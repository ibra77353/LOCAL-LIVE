بيانات الدخول الأولية إلى لوحة إدارة PrinceLive v8.0.1
====================================================
اسم المستخدم: admin
كلمة المرور: Admin123

(كلمة المرور البديلة المذكورة في config.json ضمن defaultPassword — admin123 — مقبولة أيضاً.)

افتح http://localhost/admin/ ثم أدخل البيانات أعلاه في نافذة المصادقة.
كلمة المرور مخزّنة في config.json مشفّرة بـ scrypt مع salt داخل كائن admin، ويمكن تغييرها بتوليد hash جديد.
غيّر كلمة المرور بعد أول دخول، ولا تشارك هذا الملف أو ترفع الحزمة علناً.
المصادقة الحالية Basic Auth؛ استخدمها داخل شبكة محلية موثوقة فقط ولا تعرضها مباشرة للإنترنت.
