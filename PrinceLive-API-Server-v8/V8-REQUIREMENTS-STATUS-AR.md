## ما يزال مطلوباً قبل اعتماد v8 إنتاجياً

- [ ] اختبار حقيقي على Windows 10 مع كرت USB المستخدم فعلياً.
- [ ] التحقق من أن تنسيق DirectShow وFPS المكتشفين يطابقان ما يقبله التعريف عند الالتقاط المستمر؛ parser يعتمد على صيغة إخراج FFmpeg وقد تختلف الصيغة بين الإصدارات والتعريفات.
- [ ] اختبار الصوت على جهاز المستخدم الفعلي، بما في ذلك توافق جهاز الصوت مع جهاز الفيديو.
- [ ] اختبار Nginx الفعلي وإعادة تحميل إعداداته على Windows.
- [ ] اختبار البث المتزامن بعدد القنوات الذي يستطيع المعالج تحمله؛ لا يوجد حد سحري ثابت لعدد القنوات.
- [x] إضافة fallback تلقائي إلى إعادة الترميز إذا فشل نسخ المصدر الشبكي، مع الاحتفاظ بإعداد القناة source.
- [ ] اختبار سلوك انقطاع الشبكة/USB وفقدان الصوت لفترات طويلة.
- [ ] إضافة فحص اتصال الشبكة بمصدر RTSP/HTTP مع دعم بيانات الاعتماد المخفية في الواجهة.
- [ ] مراجعة أمنية إضافية للجلسات وتغيير كلمة المرور الافتراضية؛ لا تعرض لوحة الإدارة على الإنترنت عبر HTTP.
- [ ] التحقق من مسارات Nginx وFFmpeg وFFprobe على جهاز التشغيل الفعلي.

## ما لا يمكن اعتماده دون جهاز التشغيل الفعلي
لا يمكن إعلان هذه الحزمة إصداراً إنتاجياً نهائياً موثوقاً قبل اختبار Windows 10/11 مع كرت الالتقاط الفعلي ونسخة FFmpeg وNginx المستخدمة. نجاح الاختبارات البرمجية لا يثبت توافق تعريف DirectShow أو الصوت أو قدرة المعالج على عدد القنوات المطلوب.


## تحديث واجهة النوافذ المنبثقة
- تم نقل نموذج إعدادات المنصة والخادم بالكامل إلى نافذة Modal واحدة واسعة ومقسمة إلى شبكة حقول متجاوبة.
- زر «فتح نافذة الإعدادات» هو المدخل الوحيد للنموذج؛ لم تعد حقول الإعدادات مضمنة مباشرة في صفحة لوحة التحكم.
- تأكيد حذف المصدر والقناة أصبح داخل نافذة تأكيد منسقة بدل نافذة المتصفح الافتراضية.
- نوافذ المصدر والقناة بقيت منبثقة، مع أزرار إغلاق وإلغاء وحفظ.
- عند فشل حفظ الإعدادات تبقى نافذتها مفتوحة، وعند النجاح تُغلق.
- التحقق المنفذ: محلل HTML، و`node --check` لملفات JavaScript، و`npm test` (V8 verification PASSED).
- لم يُجرَ اختبار التقاط فعلي على جهاز USB أو اختبار بث حي متعدد القنوات في هذه البيئة.
